# Code of Conduct

This project follows the Contributor Covenant principles:

- Be respectful and constructive.
- Focus critique on code, behavior, and evidence.
- Do not harass, threaten, or discriminate.
- Help maintain a professional, welcoming project space.

Reports can be sent through the repository maintainers' contact options or
GitHub's reporting features. Maintainers may remove comments, issues, pull
requests, or contributors that violate this code.
