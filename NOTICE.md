outlook-cli is an independent open-source command-line client for Microsoft
Exchange Web Services (EWS).

Microsoft, Outlook, Exchange, Microsoft 365, and related names are trademarks or
registered trademarks of Microsoft Corporation. This project is not affiliated
with, endorsed by, sponsored by, or maintained by Microsoft.

The tool uses public Exchange Web Services behavior through the third-party
`exchangelib` Python package. Compatibility depends on the target Exchange
server configuration, tenant policy, authentication method, and whether EWS is
enabled by the organization.
